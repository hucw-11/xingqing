# 心晴 · 开发计划与反馈

更新：2026-11-13。状态区分“已实现 / CI 已验证 / 真机已验收”，不能相互代替。

## 产品约定

原生 Android、中文、个人自用、容易维护。数据本地保存不上传，天气是计划中的唯一联网功能。手机/电脑同步暂缓。不引入 Hilt 或不必要的框架。
心情独立于日记，可随时记录五档感受及原因；日记一天多条。计划有清单与跨昨天/今天/明天的连续时间轴，同时展示课程。天气手动选城市，默认 07:00 提醒。三餐支持照片文字，备份不含照片，热量评估仅预留接口。

## 按批次推进

1. **A 课表稳定版（本轮 1.1）**：F03/F04、迁移、自动测试；合并一次安装验收。
2. **B 提醒与数据保护**：按 F01 结果定向修复；长空窗续排、通知点击课表、调课冲突和实例身份；原生 JSON 导出/恢复及校验。先保护课程数据，再增加私人记录。
3. **C 心情与日记闭环**：独立心情、日记列表/编辑/搜索/珍藏/草稿；同时扩充备份。“慢慢记”v1 导入：日记/课程映射、任务归到导入当天、日记按 updatedAt 合并、课程保留本地；5 MB/条数/字段校验。双向格式兼容需用样本验证。
4. **D 计划**：待办、完成状态、可选时间/提醒、跨天时间轴，统一展示课程和计划。
5. **E 回顾**：心情占比、7/30 天趋势、条目数/非空白字数/记录天数/连续天数、28 天热图、周记模板。
6. **F 生活扩展**：Open-Meteo 城市/缓存/定时提醒；三餐照片文字/漏餐/用餐时间汇总与热量接口。两者分批验收。
7. **G 打磨**：深色模式、空状态、性能、图标。同步、全屏循环闹钟另行定方案。

## 降低验收成本

每批只交一个通过 CI 的 APK；自动覆盖日期、单双周、冲突、迁移和持久化，手机只测升级保留、交互、振动和锁屏提醒。
本轮必测约 5–8 分钟；重启提醒属于一次性扩展测试，不要求界面改动后反复做。
反馈集中按编号回复“通过/失败 + 现象”。开发者负责排查 CI 错误，不让用户搬运编译日志。
每次交付提供版本、提交、CI 链接和未测边界。真机没有反馈前保持待验收。

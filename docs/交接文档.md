## 项目与协作

本地 xinqing，远程 git@github.com:hucw-11/xingqing.git，包名 com.hucw.xinqing。
用户主要依靠 AI 开发，希望中文、具体易懂且能维护。真机测试成本高：集中交付、先自动验证、提供最短测试路径。产品决策与批次见 [开发清单](开发清单.md)。

固定版本：Kotlin 1.9.24、AGP 8.5.2、Gradle 8.7、JDK 17、SDK 34/minSdk 26、Compose BOM 2024.06.00/compiler 1.5.14、Room 2.6.1/KSP 1.9.24-1.0.20。设置用 SharedPreferences。Robolectric 4.12.2 仅用于 JVM 迁移测试。

## 代码地图

- domain/Course.kt：新增 weekdays，多个 1–7；weekday 留作兼容，保存为最小选中日。业务以 weekdays 为准。
- domain/Recurrence.kt：按学期周一、开始周/持续周数/单双周展开；取消与移动关联原日期。
- domain/Overlap.kt：共同星期、时间严格重叠且周次相交才冲突；尚不含调课例外。
- domain/ReminderPlanner.kt：展开未来日期、提前分钟生成提醒。
- domain/TimetableLayout.kt：重叠课程分列，相邻课程复用列。
- data/XinqingDatabase.kt：Room v2 七个实体，课程/例外/闹钟有 DAO。MIGRATION_1_2 新增 weekdays TEXT NOT NULL DEFAULT ''，旧 weekday 转字符串，不删除旧表或旧记录。
- data/mapper/CourseMapper.kt：CSV 多日读写、去重排序；空值兼容原 weekday。
- ui/screens/CourseEditScreen.kt：两行多选星期、轮盘、持续分钟，禁止空选。
- ui/screens/TimetableScreen.kt：每分钟 1.5dp，默认 07:00–22:00，早晚课程自动扩展；固定表头、横纵滚动、124dp 列、重叠扩列；全部课程仍是编辑入口。
- ui/screens/AdjustCourseScreen.kt：原日期取消 + 目标日期增加，仓库保存后重排。
- reminder/AlarmScheduler.kt：Mutex 内取消旧任务再排未来 21 天/最多 200 条；自增 id 与唯一 URI 标识 PendingIntent；无精确权限降级。
- reminder/CourseReminderReceiver.kt：触发时重新查课程/例外，共用 Recurrence 支持多日。
- reminder/Notifications.kt、Vibration.kt：三渠道、直接振动器，真机效果待确认。
- ui/screens/HomeScreen.kt：今日课 + 提醒测试/诊断；后续诊断移至设置。
- ui/navigation/XinqingNavHost.kt：今天/日记/课表/回顾/设置；日记与回顾占位。

## 数据与已知限制

不能使用破坏性迁移。新增字段需升版本并迁移；覆盖安装，不可用卸载解决问题。升级后不能直接降级旧 APK。
改星期保留原取消/移动例外，不清理历史。已调过的课程再次调课仍可能把目标日当原日期，下一批需传原实例身份。
调课目标冲突、通知点击进入课表尚未实现。21 天无提醒触发且不打开 App 时，排期窗口可能不续期。
极短课程块容纳不下全部文字，可从全部课程编辑；时间列横向滑动时会离开视口，后续可优化。
日记/心情/计划/三餐实体不等于业务已完成。天气未实现。慢慢记备份参考 ../manmanji/dist/storage.js。
